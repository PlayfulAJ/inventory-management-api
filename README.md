# Inventory Management API

## Overview

The Inventory Management API allows users to manage inventory items. The application connects to the OpenFoodFacts API to retrieve product information using a barcode.

A simple CLI is also included to allow users to interact with the API from the terminal.
---

## Features

* View all inventory items
* View a single inventory item by ID
* Add a new inventory item
* Update an item's price or stock
* Delete an inventory item
* Search products using the OpenFoodFacts API
* Simple CLI for interacting with the API
* Unit tests using Pytest

---

## Technologies Used

* Python
* Flask
* Requests
* Pytest
